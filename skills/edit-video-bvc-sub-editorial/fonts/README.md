# Fonts (SIL Open Font License 1.1, đủ dấu tiếng Việt)
Tải từ Google Fonts (fonts.gstatic.com), bản tĩnh:
- PlayfairDisplay-Regular / Italic / MediumItalic: Playfair Display, Claus Eggers Sørensen. Thay cho serif Didone cao gầy của mẫu (engine ép ngang 82–86%).
- Inter-Light / SemiBold / Bold / ExtraBold: Inter, Rasmus Andersson. Thay cho Helvetica Neue.
Giấy phép: OFL.txt (dùng chung cho cả hai họ font, cho phép dùng thương mại, nhúng vào video).
Muốn đổi font: sửa bảng FONTS trong scripts/ed_overlay.py (tên font trong ASS, file, % ép ngang).
